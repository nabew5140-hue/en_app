# 円（en）

このアプリは１日１回だけ円を描きそれを保存する、というシンプルなもの
禅の「円相」をイメージし、１日のなかで「何も考えない時間」を作り出すことを目的にしています。

## 概要

このアプリは、RUNTEQ での学習の一環として、卒業制作に向けて作成した MVP です。
AI を壁打ち相手にしながら、設計やコードのレビューを行いつつ制作しています。

## コンセプト

禅の書画の一つ「円相」をイメージしています。

- 描いた円は誰からも評価されず、ただ記録として保存
- １日１回しか書けない、不可逆なもの
- 現実から接続され続ける思考の余白（何も考えないという時間）を作る
- 壁紙や待ち受けにして自らの内省を図る

## アプリ開発の背景

作者が家族の精神的なトラブルに対応したことをきっかけに、日々の違和感に自ら気付けるようなアプリを作りたいと思い発案。
違和感に気づくという行為を思い浮かべたとき一番はじめに頭によぎったのは仙厓さん（仙厓義梵）の円相図でした。
円をお饅頭（またはお餅）に見立てて「これをたべてお茶でものみなさい」と書かれた書が添えられたものです。
禅の教えを庶民の手の届く形で表現されたその円相図の気軽さに、こういう形で日々の自分を記録することで自分の違和感や変化に気づくきっかけになるんではないか、と思いました。
自らの内省をいざしよう！と思うと腰が重くなりますが、ただ丸をかこう！と思えばいくらか手軽かと思います。
日々の自分を「円を描く」ということで記録し、観察することで自らの変化に気づき内省へとつなげられればいいな、と思います。

>**注:[仙厓義梵とは]仙厓 義梵（せんがい ぎぼん、寛延3年（1750年）4月 - 天保8年10月7日（1837年11月4日））は江戸時代の臨済宗古月派の禅僧、画僧[1]。禅味溢れる絵画で知られる。

>出典: フリー百科事典『ウィキペディア（Wikipedia）』仙厓義梵より

## ターゲットユーザー

- 家族を想定（60代～70代）
- 電子機器の扱いに不慣れな方でも使いやすいシンプルなUI

## 機能

- 円の描画(Canvas)
- 「完了」ボタン
- 円の保存(LocalStorage)
- 「今日の円を見る」ボタン
>**注:SNSへの共有ボタンは今後の開発でつけることを考えていません

- ユーザー登録・ログイン機能
- 過去の円を重ねて表示(スワイプで閲覧)

- 和綴じの本としての実体化

## 保存方法

- 第一段階: LocalStorage

## 開発の進め方

1. 第一段階:ローカルストレージに保存(MVP)
2. Canvas で円を描く
3. 「完了」ボタンで保存(LocalStorage)
4. 「今日の円を見る」ボタンで確認(スキップして終了も可)
>*ユーザーからフィードバックをもらい、学習カリキュラムを進めながらその他の機能の実装をしていきたいです。
