# 円（en）

このアプリは１日１回だけ円を描きそれを保存する、というシンプルなもの。
禅の「円相」をイメージしています。

>**注[円相とは]:円相（えんそう）は、禅における書画のひとつで、図形の丸（円形）を一筆で描いたもの。「一円相（いちえんそう）」「円相図（えんそうず）」などとも呼ばれる。
>悟りや真理、仏性、宇宙全体などを円形で象徴的に表現したものとされるが、その解釈は見る人に任される。
>出典: フリー百科事典『ウィキペディア（Wikipedia）』円相より

## 概要

このアプリは、RUNTEQ での学習の一環として、卒業制作に向けて作成した MVP です。
AI を壁打ち相手にしながら、設計やコードのレビューを行いつつ制作しています。

## コンセプト

禅の書画の一つ「円相」をイメージしています。

- 描いた円は誰からも評価されず、ただ記録として保存
- １日１回しか書けない、不可逆なもの
- 現実から接続され続ける思考の余白（何も考えないという時間）を作る
- 壁紙や待ち受けにして自らの内省を図る

## アプリ開発の背景

作者が家族の精神的なトラブルに対応したことをきっかけに、日々の違和感に自ら気付けるようなアプリを作りたいと思い発案。
自らの内省をいざしよう！と思うと腰が重くなるが、ただ丸をかこう！と思えばいくらか手軽かと思います。
日々の自分を「円を描く」ということで記録し、観察することで自らの変化に気づくきっかけになればいいなと思います。

## MVPの機能

>**検証内容：「円を描く→保存→見返す」というサイクルで内省が促されるのか

- 円相についての説明図
- ユーザー登録・ログイン機能
- 円の描画(Canvas)
- 「完了」ボタン
- 円の保存(DB)
- 「今日の円を見る」ボタン
- 今日の円を大きく表示
- 「過去の円を見る」ボタン
- 過去の円を一覧で表示
- 「閉じる」ボタン（「今日の円を見る」で確認が必要ない場合）
>**注:SNSへの共有ボタンは今後の開発でつけることを考えていません

## 今後追加したい機能

- 1日1回の制約 =>出来たらUIで24時間を円としてあらわして時間になったら描けるみたいなグラフィックにしたい
- 書き直し不可の制約
- 過去の円を重ねて表示(スワイプで閲覧)
- パラパラ漫画風のアニメーション
- インクに残量をもたせる
- カラーモード(PC内時刻に基づき朝～昼～夜とランダムに色を変える) =>最終的に白黒とカラーモードが選べて、保存した後でも変更できるようにしたい
- 和綴じの本としての実体化
