# 円（en）

このアプリは１日１回だけ円を描きそれを保存する、というシンプルなもの。
禅の「円相」をイメージしています。

>**注[円相とは]:円相（えんそう）は、禅における書画のひとつで、図形の丸（円形）を一筆で描いたもの。「一円相（いちえんそう）」「円相図（えんそうず）」などとも呼ばれる。
>悟りや真理、仏性、宇宙全体などを円形で象徴的に表現したものとされるが、その解釈は見る人に任される。
>出典: フリー百科事典『ウィキペディア（Wikipedia）』円相より

## 概要

このアプリは、RUNTEQ での学習の一環として、卒業制作に向けて作成した MVP です。
AI を壁打ち相手にしながら、設計やコードのレビューを行いつつ制作しています。

## コンセプト

禅の書画の一つ「円相」をイメージしています。

- 描いた円は誰からも評価されず、ただ記録として保存
- １日１回しか書けない、不可逆なもの
- 現実から接続され続ける思考の余白（何も考えないという時間）を作る
- 壁紙や待ち受けにして自らの内省を図る

## アプリ開発の背景

作者が家族の精神的なトラブルに対応したことをきっかけに、日々の違和感に自ら気付けるようなアプリを作りたいと思い発案。
違和感に気づくという行為を思い浮かべたとき一番はじめに頭によぎったのは仙厓さん（仙厓義梵）の円相図でした。
>**注:[仙厓義梵とは]仙厓 義梵（せんがい ぎぼん、寛延3年（1750年）4月 - 天保8年10月7日（1837年11月4日））は江戸時代の臨済宗古月派の禅僧、画僧[1]。禅味溢れる絵画で知られる。
>出典: フリー百科事典『ウィキペディア（Wikipedia）』仙厓義梵より
円をお饅頭（またはお餅）に見立てて「これをたべてお茶でものみなさい」と書かれた書が添えられたものです。
禅の教えを庶民の手の届く形で表現されたその円相図の気軽さに、こういう形で日々の自分を記録することで自分の違和感や変化に気づくきっかけになるんではないか、と思いました。
自らの内省をいざしよう！と思うと腰が重くなりますが、ただ丸をかこう！と思えばいくらか手軽かと思います。
日々の自分を「円を描く」ということで記録し、観察することで自らの変化に気づき内省へとつなげられればいいな、と思います。

1. 円を描くという行為が、内省のきっかけになるか
2. 過去の円を見返すことで、自分の変化に気づけるか
3. 毎日続けたくなる体験になっているか

## 検証 (実践)

>**検証内容：「円を描く→保存→見返す」というサイクルで内省が促されるのか

今の段階で、このMVPを作る価値があるのか１週間実際に紙と筆ペンで円相を描いてみる

- 1週間紙と筆ペンで毎日円を描く
- 円を描く前後の気持ちを記録、変化があるのか？
- 円を描いた後、前日までに書いた円を見返し気持ちを記録、変化はあるのか？
- 検証結果をもとにMVPの機能を再定義、または開発の中止を決める

## MVPの機能

- 円相についての説明図
- ユーザー登録・ログイン機能
- 円の描画(Canvas)
- 「完了」ボタン
- 円の保存(DB)
- 「今日の円を見る」ボタン
- 今日の円を大きく表示
- 「過去の円を見る」ボタン
- 過去の円を一覧で表示
- 「閉じる」ボタン（「今日の円を見る」で確認が必要ない場合）
>**注:SNSへの共有ボタンは今後の開発でつけることを考えていません

## 今後追加したい機能

### 優先度高

- 1日1回の制約 =>出来たらUIで24時間を円としてあらわして時間になったら描けるみたいなグラフィックにしたい
- 書き直し不可の制約
- カラーモード(PC内時刻に基づき朝～昼～夜とランダムに色を変える) =>最終的に白黒とカラーモードが選べて、保存した後でも変更できるようにしたい

### 優先度中

- 過去の円を重ねて表示(スワイプで閲覧)
- インクに残量をもたせる

### 優先度低

- パラパラ漫画風のアニメーション
- 和綴じの本としての実体化

## 使用技術
