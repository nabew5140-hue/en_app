# 円（en）

このアプリは１日１回だけ円を描きそれを保存する、というシンプルなもの
禅の「円相」をイメージし、１日のなかで「何も考えない時間」を作り出すことを目的にしています。

## 概要

このアプリは、RUNTEQ での学習の一環として、卒業制作に向けて作成した MVP です。
AI を壁打ち相手にしながら、設計やコードのレビューを行いつつ制作しています。

## コンセプト

禅の書画の一つ「円相」をイメージしています。

- 描いた円は誰からも評価されず、ただ記録として保存
- １日１回しか書けない、不可逆なもの
- 現実から接続され続ける思考の余白（何も考えないという時間）を作る
- 壁紙や待ち受けにして自らの内省を図る

## アプリ開発の背景

作者が家族の精神的なトラブルに対応したことをきっかけに、日々の違和感に気付けるようなアプリを作りたいと思い発案
些細な違和感を見逃したことで病状が進んでいったという反省、自戒を込めて自らと向き合うということを手軽にできればと思った
自らの内省をいざしよう！と思うと腰が重くなるが、ただ丸をかこう！と思えばいくらか手軽かと思う
個人的にトラブルを抱えた家族をみていていちばん辛そうだなと思ったのは、頭の中に常に不安が居座っていることだった
その思考を具体的な行動（１日１回円を描く）で一時的に止めることを目標としている

## ターゲットユーザー

- 家族を想定（60代～70代）
- 電子機器の扱いに不慣れな方でも使いやすいシンプルなUI

## 機能

- 円の描画(Canvas)
- 「完了」ボタン
- 円の保存(LocalStorage)
- 「今日の円を見る」ボタン
>**注:SNSへの共有ボタンは今後の開発でつけることを考えていません

## 今後追加したい機能
- 1日1回の制約 =>出来たらUIで24時間を円としてあらわして時間になったら描けるみたいなグラフィックにしたい
- 書き直し不可の制約
- ユーザー登録・ログイン機能
- 過去の円を重ねて表示(スワイプで閲覧)
- パラパラ漫画風のアニメーション
- インクに残量をもたせる
- カラーモード(PC内時刻に基づき朝～昼～夜とランダムに色を変える) =>最終的に白黒とカラーモードが選べて、保存した後でも変更できるようにしたい
- 和綴じの本としての実体化

## 保存方法

- 第一段階: LocalStorage
- 第二段階: Rails + DB

## 開発の進め方

1. 第一段階:ローカルストレージに保存(MVP)
2. Canvas で円を描く
3. 「完了」ボタンで保存(LocalStorage)
4. 「今日の円を見る」ボタンで確認(スキップして終了も可)
>*ユーザーからフィードバックをもらい、学習カリキュラムを進めながらその他の機能の実装をしていきたいです。
